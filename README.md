# 🧠 記憶翻牌大挑戰 (Memory Match Game)

一個精緻、流暢且具有現代暗黑流光視覺風格的 16 張卡牌記憶翻牌配對遊戲。使用 React 19 + Vite 打造，支援計時、步數記錄、歷史最快紀錄與全繁體中文介面。

🔗 **線上遊玩 (Live Demo)**: https://ginoyu1028-png.github.io/memory-card-game/

---

## ✨ 遊戲特色
- 🃏 **16 張牌 (4x4 網格)**：包含 8 組精美主題圖案（🚀 火箭、🪐 土星、🌟 星星、🛸 飛碟、👾 怪獸、🌈 彩虹、💎 寶石、⚡ 閃電）。
- 💫 **流暢 3D 翻牌與消除特效**：真實的 3D 卡牌翻轉體驗，配對成功後會發光並優雅縮小消除。
- ⏱️ **計時與翻牌步數統計**：翻開第一張牌即開始計時，精確記錄每一次翻牌步數與即時配對進度。
- 🏆 **歷史最快紀錄保存**：支援記錄個人歷史最快通關時間（本地儲存 `localStorage`），隨時挑戰刷新最佳成績。
- 🔊 **Web Audio API 擬真音效**：輕量化無延遲音效（翻牌聲、配對成功和弦、失敗提示音、通關號角），並附靜音切換。
- 🎉 **通關星級評鑑與煙火慶祝**：全部消除後跳出通關彈窗，依步數給予星級評分（★★★）並施放慶祝彩帶煙火！
